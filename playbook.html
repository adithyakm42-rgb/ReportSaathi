1. The Antigravity Operating Model

Google Antigravity is an agentic AI development environment capable of inspecting workspaces, executing shell commands, authoring multi-file modules, and scheduling reactive background tasks. Achieving flawless results requires understanding its architectural guardrails:

1.1 Sandbox Isolation: Standard Mode vs. Bypass Mode

  • Standard Sandbox Mode (BypassSandbox: false): By default, Antigravity commands run in an isolated environment with zero outbound network access. Local compilation (npm run build), unit tests (python -m unittest), and local file operations must always run sandboxed without asking for user elevation.
  • Bypass Sandbox Mode (BypassSandbox: true): Disables network isolation and allows external connections (e.g., git fetch origin, git push origin, npm install). Antigravity rules dictate: Always attempt sandboxed first; only elevate the single network-dependent step.

1.2 The Golden Rule: Continuous Remote Git Synchronization

MANDATORY WORKFLOW DIRECTIVE: In collaborative multi-developer hackathon teams, teammates push code independently. Before proceeding to any new step or drafting new code, Antigravity MUST execute git fetch origin and inspect git log HEAD..origin/main to avoid catastrophic merge collisions or redundant work.

2. The Pre-Prompt Verification Framework

Before submitting any instruction to Antigravity, apply the 5-Point Pre-Flight Checklist to guarantee agent alignment:

  1. Remote Git State: Has another team member pushed changes to main? (Run git fetch origin).
  2. Role Scope Validation: Does this task belong to Person 3, or will it intrude on Person 1 or 2's documented ownership?
  3. Environment Prerequisite Check: Are required tools installed? (e.g., Tesseract binary at C:\Program Files\Tesseract-OCR\tesseract.exe, Node.js v20+, Python 3.12+).
  4. Medical Safety Grounding: Does this prompt violate safety rules (e.g., attempting disease diagnosis, medication dosage modification, or inventing reference ranges)?
  5. Artifact Verification: Do downstream files exist before asking the agent to test them?

4. Antigravity Operational Best Practices & Troubleshooting

Issue / Error Encountered Root Cause in Antigravity Proven Solution & Prevention
getaddrinfo() thread failed to start Standard Sandbox Mode blocks outbound network by default. Re-run the command with BypassSandbox: true and the exact same toolSummary.
Write-Progress console buffer error (0x5) PowerShell Expand-Archive fails in headless terminal buffers on Windows. Use Python standard library (zipfile.ZipFile) to extract archives cleanly.
Pytest connection timeout in sandbox Pytest was not installed locally and pip install blocked in offline sandbox. Use Python's built-in unittest module (python -m unittest discover tests). Zero external dependencies.
Unused variable compilation error (TS6133) TypeScript strict mode rejects imported but unused interfaces in React components. Run npm run build locally to catch TS errors before committing. Strip unused imports.
Phantom lab values on non-medical uploads Frontend mock client fell back silently to sample-report.json on backend errors. Implement active backend health probe and empty state guard (values.length === 0) in UI.
